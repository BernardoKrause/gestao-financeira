# Multiusuário Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the Gestão Financeira Rails app from single-user to multiuser, with public self-registration and full data isolation between accounts.

**Architecture:** Add a `user_id` column directly to `categories`, `transactions`, `recurring_entries`, and `settings` (no derived ownership through joins). Every controller query and the `Setting` model's internal balance math scope through `current_user`/`user` instead of querying model classes globally. Registration goes through Devise's `:registerable` module with a thin controller override that seeds a new `Setting` and 13 default categories via a `UserOnboarding` service (mirrors the existing `RecurringEntryGenerator.call` service-object pattern already in the codebase). The old single-user `SetupController`/`/setup` bootstrap flow is deleted outright.

**Tech Stack:** Ruby on Rails 8.1, Devise, RSpec + FactoryBot, SQLite (dev/test).

## Global Constraints

- Every query for a user's `Category`/`Transaction`/`RecurringEntry`/`Setting` MUST go through `current_user` (or `user.<association>` inside `Setting`) — never the bare model class. This is the isolation boundary; a bare `Category.find(...)` etc. anywhere is a bug.
- Categories are private per user (not shared).
- Registration is public — no invite/approval gate, matching the existing "sign in immediately after creating the account" behavior from the old setup flow.
- New account onboarding creates exactly one `Setting` (`initial_balance: 0`) and these 13 categories:
  - Despesas: Aluguel, Assinatura, Cartão de Crédito, Contas de Casa, Esporte, Estética, Lanchonete/Restaurante, Mercado, Padaria, Saúde
  - Receitas: Renda Extra, Salário, Vendas
- A `Transaction`/`RecurringEntry` whose `category` belongs to a different user than the record's own `user` is invalid — this closes the cross-tenant IDOR gap where a crafted `category_id` param could reference another user's category.
- Spec: `docs/superpowers/specs/2026-09-03-multiuser-design.md`.

## Sequencing note

This is an incremental refactor across many consumers of the same model
layer. Task 2 changes `Setting`/`Category`/`Transaction`/`RecurringEntry` in
ways that controllers, views and specs from Tasks 4–8 still assume the old
(unscoped) shape — e.g. `Setting.instance` is removed in Task 2 but
`DashboardData` isn't updated to `current_user.setting` until Task 7. Running
the **whole** `bundle exec rspec` suite between Task 2 and Task 9's Step 14
will show failures in specs whose task hasn't landed yet — that's expected,
not a regression. Each task's own "run it" step (scoped to the files that
task touches) is the authoritative pass/fail signal until Task 9 Step 14,
where the full suite must be green.

`app/models/recurring_entry.rb`:

```ruby
class RecurringEntry < ApplicationRecord
  enum :kind, { expense: 0, income: 1 }

  belongs_to :user
  belongs_to :category
  has_many :transactions, dependent: :nullify

  validates :description, presence: true
  validates :amount, numericality: { greater_than: 0 }
  validates :day_of_month, presence: true, numericality: { only_integer: true, greater_than_or_equal_to: 1, less_than_or_equal_to: 31 }
  validates :start_date, presence: true
  validates :installments, numericality: { only_integer: true, greater_than_or_equal_to: 1 }, allow_nil: true
  validate :category_belongs_to_user

  scope :active, -> { where(active: true) }

  # Computed, not persisted: with `installments` blank, the entry recurs with
  # no end. With N installments, start_date's own month counts as
  # installment 1, so the Nth (last) installment falls (N-1) months later —
  # on day_of_month within that month, clamped to the month's length the
  # same way RecurringEntryGenerator clamps the fire date itself.
  def end_date
    return nil if installments.blank?

    last_month = start_date.beginning_of_month + (installments - 1).months
    day = [ day_of_month, last_month.end_of_month.day ].min
    Date.new(last_month.year, last_month.month, day)
  end

  private

  def category_belongs_to_user
    return if category.nil? || user.nil? || category.user_id == user_id

    errors.add(:category, "deve pertencer ao mesmo usuário")
  end
end
```

- [ ] **Step 5: Scope `Setting`'s internal math to its owner and drop the singleton**

`app/models/setting.rb`:

```ruby
class Setting < ApplicationRecord
  CONFIDENCE_LEVELS = %i[confirmed recurring all].freeze

  belongs_to :user

  validates :initial_balance, numericality: true

  def current_balance(as_of: Date.current)
    initial_balance + user.transactions.where(date: ..as_of).sum(&:signed_amount)
  end

  def projected_month_end_balance(as_of: Date.current)
    current_balance(as_of: as_of) +
      pending_recurring_income_total(as_of: as_of) -
      pending_recurring_expense_total(as_of: as_of)
  end

  def projected_balance_for(confidence:, as_of: Date.current)
    case confidence.to_sym
    when :confirmed
      current_balance(as_of: as_of)
    when :recurring
      projected_month_end_balance(as_of: as_of)
    when :all
      projected_month_end_balance(as_of: as_of) +
        pending_one_off_income_total(as_of: as_of) -
        pending_one_off_expense_total(as_of: as_of)
    else
      raise ArgumentError, "unknown confidence level: #{confidence.inspect}"
    end
  end

  def financial_health_status(as_of: Date.current)
    financial_health_status_for(confidence: :recurring, as_of: as_of)
  end

  def financial_health_status_for(confidence:, as_of: Date.current)
    projected = projected_balance_for(confidence: confidence, as_of: as_of)
    return :critical if projected.negative?
    return :warning if monthly_recurring_expense_total(as_of: as_of) > monthly_recurring_income_total(as_of: as_of)

    :healthy
  end

  def pending_recurring_income_total(as_of: Date.current)
    pending_recurring_entries(as_of: as_of).select(&:income?).sum(&:amount)
  end

  def pending_recurring_expense_total(as_of: Date.current)
    pending_recurring_entries(as_of: as_of).select(&:expense?).sum(&:amount)
  end

  def pending_one_off_income_total(as_of: Date.current)
    pending_one_off_transactions(as_of: as_of).select(&:income?).sum(&:amount)
  end

  def pending_one_off_expense_total(as_of: Date.current)
    pending_one_off_transactions(as_of: as_of).select(&:expense?).sum(&:amount)
  end

  def cash_flow_series(month: Date.current, as_of: Date.current, confidence: :recurring)
    days = (month.beginning_of_month..month.end_of_month).to_a

    {
      labels: days.map(&:day),
      historical: days.map { |day| day <= as_of ? current_balance(as_of: day) : nil },
      projected: days.map { |day| day < as_of ? nil : projected_balance_on(day, as_of: as_of, confidence: confidence) }
    }
  end

  private

  def pending_recurring_entries(as_of:)
    return [] if as_of.day == as_of.end_of_month.day

    user.recurring_entries.active.select { |entry| pending?(entry, as_of) }
  end

  def pending?(entry, as_of)
    entry.day_of_month > as_of.day && fires_within_month?(entry, as_of)
  end

  # Counts an entry whether or not its day_of_month has already passed this
  # month — answers "is this a structurally deficit month", not "what's
  # left to happen". financial_health_status_for uses this (not
  # pending_recurring_*) for every confidence level, so :warning doesn't
  # collapse to :healthy the moment every recurring entry for the month has
  # already fired, and doesn't vary with which balance view is selected.
  def monthly_recurring_income_total(as_of:)
    monthly_recurring_entries(as_of: as_of).select(&:income?).sum(&:amount)
  end

  def monthly_recurring_expense_total(as_of:)
    monthly_recurring_entries(as_of: as_of).select(&:expense?).sum(&:amount)
  end

  def monthly_recurring_entries(as_of:)
    user.recurring_entries.active.select { |entry| fires_within_month?(entry, as_of) }
  end

  def fires_within_month?(entry, as_of)
    fire_date = Date.new(as_of.year, as_of.month, [ entry.day_of_month, as_of.end_of_month.day ].min)
    entry.start_date <= fire_date && (entry.end_date.nil? || entry.end_date >= fire_date)
  end

  def pending_one_off_transactions(as_of:)
    user.transactions.where(date: (as_of + 1)..as_of.end_of_month, recurring_entry_id: nil)
  end

  def projected_balance_on(day, as_of:, confidence:)
    return current_balance(as_of: as_of) if day == as_of

    case confidence.to_sym
    when :confirmed
      current_balance(as_of: as_of)
    when :recurring
      current_balance(as_of: as_of) + recurring_net_between(as_of + 1, day)
    when :all
      current_balance(as_of: as_of) + recurring_net_between(as_of + 1, day) + one_off_net_between(as_of + 1, day)
    else
      raise ArgumentError, "unknown confidence level: #{confidence.inspect}"
    end
  end

  def recurring_net_between(from, to)
    user.recurring_entries.active.sum do |entry|
      (from..to).sum { |date| fires_on?(entry, date) ? entry_signed_amount(entry) : 0 }
    end
  end

  def one_off_net_between(from, to)
    user.transactions.where(date: from..to, recurring_entry_id: nil).sum(&:signed_amount)
  end

  def fires_on?(entry, date)
    return false unless entry.start_date <= date && (entry.end_date.nil? || entry.end_date >= date)

    date.day == [ entry.day_of_month, date.end_of_month.day ].min
  end

  def entry_signed_amount(entry)
    entry.income? ? entry.amount : -entry.amount
  end
end
```

class CategoriesController < ApplicationController
  before_action :set_category, only: %i[show edit update destroy]

  def index
    @categories = current_user.categories.order(:name)
  end

  def show; end

  def new
    @category = current_user.categories.new
  end

  def edit; end

  def create
    @category = current_user.categories.new(category_params)
    if @category.save
      redirect_to categories_path, notice: "Categoria criada com sucesso."
    else
      render :new, status: :unprocessable_entity
    end
  end

  def update
    if @category.update(category_params)
      redirect_to categories_path, notice: "Categoria atualizada com sucesso."
    else
      render :edit, status: :unprocessable_entity
    end
  end

  def destroy
    if @category.destroy
      redirect_to categories_path, notice: "Categoria removida."
    else
      redirect_to categories_path, alert: @category.errors.full_messages.to_sentence
    end
  end

  private

  def set_category
    @category = current_user.categories.find(params[:id])
  end

  def category_params
    params.require(:category).permit(:name, :kind)
  end
end

module DashboardData
  extend ActiveSupport::Concern

  PT_MONTHS = %w[janeiro fevereiro março abril maio junho julho agosto setembro outubro novembro dezembro].freeze

  included do
    helper_method :cash_flow_series
  end

  private

  def load_dashboard_data
    @today = Date.current
    @setting = current_user.setting
    @current_balance = @setting.current_balance(as_of: @today)
    @receita_prevista = @setting.pending_recurring_income_total(as_of: @today)
    @despesa_prevista = @setting.pending_recurring_expense_total(as_of: @today)
    @projected_balance = @setting.projected_month_end_balance(as_of: @today)
    @financial_health_status = @setting.financial_health_status(as_of: @today)

    @receita_confirmada_mes = current_month_confirmed_income
    @receita_pendente_mes = @receita_prevista
    @receita_total_esperada_mes = @receita_confirmada_mes + @receita_pendente_mes
    @pct_receita_confirmada = revenue_percentage(@receita_confirmada_mes)
    @pct_receita_pendente = revenue_percentage(@receita_pendente_mes)
    @current_month_label = month_label(current_month_value)

    @selected_month = params[:month].presence || current_month_value
    @month_options = build_month_options
    @selected_month_label = @month_options.find { |_label, value| value == @selected_month }&.first

    @selected_category_id = params[:category_id].presence
    @category_options = current_user.categories.order(:name).pluck(:name, :id)

    # Resumo and Histórico both reflect the same selected period and category.
    @transactions = filtered_transactions
    @month_income_total = @transactions.select(&:income?).sum(&:amount)
    @month_expense_total = @transactions.select(&:expense?).sum(&:amount)
  end

  def cash_flow_series
    @cash_flow_series ||= @setting.cash_flow_series(month: @today, as_of: @today, confidence: @confidence || :recurring)
  end

  def current_month_value
    @today.strftime("%Y-%m")
  end

  def build_month_options
    months_with_data = current_user.transactions.distinct.pluck(:date).map { |date| date.strftime("%Y-%m") }
    all_months = (months_with_data + [ current_month_value ]).uniq.sort.reverse

    [ [ "Todos os meses", "all" ] ] + all_months.map { |month| [ month_label(month), month ] }
  end

  def month_label(month_value)
    year, month = month_value.split("-").map(&:to_i)
    "#{PT_MONTHS[month - 1].capitalize} de #{year}"
  end

  def filtered_transactions
    scope = current_user.transactions.includes(:category).order(date: :desc)
    range = selected_month_range
    scope = scope.where(date: range) if range
    scope = scope.where(category_id: @selected_category_id) if @selected_category_id
    scope
  end

  def selected_month_range
    return nil if @selected_month == "all"

    month = Date.strptime(@selected_month, "%Y-%m")
    month.beginning_of_month..month.end_of_month
  rescue ArgumentError, TypeError
    @today.beginning_of_month..@today.end_of_month
  end

  def current_month_confirmed_income
    current_user.transactions.income.where(date: @today.beginning_of_month..@today).sum(:amount)
  end

  def revenue_percentage(part)
    return 0 if @receita_total_esperada_mes.to_f.zero?

    (part.to_f / @receita_total_esperada_mes * 100).round(1)
  end
end

class QuickEntriesController < ApplicationController
  include DashboardData

  def create
    @kind = params[:kind].presence_in(%w[expense income])

    if @kind.nil?
      render_dashboard_with_error(nil)
      return
    end

    if params[:fixed] == "1"
      create_recurring_entry
    else
      create_transaction
    end
  end

  private

  def create_transaction
    @transaction = Transaction.new(
      user: current_user,
      description: params[:description],
      amount: params[:amount],
      kind: @kind,
      date: params[:date],
      category_id: params[:category_id]
    )

    if @transaction.save
      redirect_to root_path, notice: "Lançamento registrado."
    else
      render_dashboard_with_error(@transaction)
    end
  end

  def create_recurring_entry
    if params[:parcelado] == "1"
      start_date = safe_parse_date(params[:start_date])
      day_of_month = start_date&.day
      installments = params[:installments].presence
    else
      start_date = Date.current
      day_of_month = params[:day_of_month]
      installments = nil
    end

    @recurring_entry = RecurringEntry.new(
      user: current_user,
      description: params[:description],
      amount: params[:amount],
      kind: @kind,
      day_of_month: day_of_month,
      start_date: start_date,
      installments: installments,
      category_id: params[:category_id]
    )

    if @recurring_entry.save
      RecurringEntryGenerator.call
      redirect_to root_path, notice: "Recorrência criada."
    else
      render_dashboard_with_error(@recurring_entry)
    end
  end

  def safe_parse_date(value)
    Date.parse(value) if value.present?
  rescue ArgumentError, TypeError
    nil
  end

  def render_dashboard_with_error(record)
    load_dashboard_data
    @quick_entry_kind = @kind
    @quick_entry_record = record
    render "dashboard/index", status: :unprocessable_entity
  end
end

class UserOnboarding
  DEFAULT_CATEGORIES = {
    expense: [ "Aluguel", "Assinatura", "Cartão de Crédito", "Contas de Casa", "Esporte", "Estética", "Lanchonete/Restaurante", "Mercado", "Padaria", "Saúde" ],
    income: [ "Renda Extra", "Salário", "Vendas" ]
  }.freeze

  def self.call(user)
    new(user).call
  end

  def initialize(user)
    @user = user
  end

  def call
    user.create_setting!(initial_balance: 0)
    DEFAULT_CATEGORIES.each do |kind, names|
      names.each { |name| user.categories.create!(name: name, kind: kind) }
    end
  end

  private

  attr_reader :user
end
